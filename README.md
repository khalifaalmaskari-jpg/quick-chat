# Quick Chat

A lightweight mobile web app for opening a WhatsApp chat with any phone number without saving it as a contact.

## Live app

Once GitHub Pages is enabled, the app is available at:

https://khalifaalmaskari-jpg.github.io/quick-chat/

## Usage

Open the site, select the country code, enter the phone number, optionally add a message, and tap **Open Chat**.

Designed for mobile use and can be added to the iPhone Home Screen.
